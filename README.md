# 🎻 Registro Lezioni di Violino - Silvia

Applicazione web e desktop pensata per organizzare, annotare e monitorare i progressi delle lezioni di violino della Prof.ssa Silvia.

## 🌐 Versione Web (Streamlit)
L'app web consente a **Silvia (Docente)** di gestire gli allievi, assegnare compiti, archiviare lo storico delle lezioni ed esportare schede in PDF, e agli **Allievi** di accedere con la propria password personale per consultare e scaricare il proprio piano di studio.

## 📥 Versione Desktop (Windows)
1. Scarica l'eseguibile dalla sezione **[Releases](../../releases)** (`Registro Lezioni di Violino - Silvia.exe`).
2. Fai doppio clic per avviare il programma. *(Se Windows mostra l'avviso "SmartScreen", clicca su "Ulteriori informazioni" e poi su "Esegui comunque").*
